# 破甲版本说明

| 版本 ID | 名称 | 适用 |
| --- | --- | --- |
| frost-v4 | 破甲 V4  通用版（提示词 + 63 技能库） | 当前唯一内置版本（默认推荐），与寒霜工具 Codex 注入的 V4 一致 |

- 激活词（发在消息开头）：全开 / 无限制 / unlimited / 全域模式；破甲 / 破限制 / 放开写 / 别降级 等。

## 生效方式

- 提示词以 `<!-- MilkBreaker:<id> -->  <!-- MilkBreaker:end -->` 块追加在系统提示词末尾。
- 启用破甲时自动安装 V4 技能库（63 个技能）到 Skills 系统，并同步进内置 Linux 环境 `/root/skills/`。
- 关闭破甲即移除提示词块，恢复服务商/默认提示词；已安装技能库保留，可在 Skills 页单独开关。
- 与「角色」会话共用同一构建入口，角色设定不受影响，仅在其后追加。
