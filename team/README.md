# 团队协作

普通聊天继续使用「Agent 人设」的主副卡。侧栏底部点击「团队协作」，进入成员私聊和项目群；点击「普通聊天」返回原来的会话。

1. 在团队左上角「＋」创建成员或项目群，也可让主理人创建。每个成员独立选择已配置的 DSH 模型。
2. 在「设置 → Agent 人设」点击某张卡的「创建团队成员」，把正文复制为成员的初始设定。主卡创建主理人，副卡创建专项成员。普通聊天的当前组合保持原样，成员设定后续在团队中单独编辑。
3. 项目群设置工作目录，由管理员接收任务并通过 @ 派活；成员完成后回群报告。文件、命令、浏览器和已接入的 MCP 沿用当前宿主的工具和权限，其他工具仍按需加载。
4. 手机上使用本机模式时，团队运行在手机；电脑模式使用已连接电脑的团队。账号、团队和工作目录各端保存，不自动混合两端数据。

已导入并启用的手机技能及技能包对团队登记的工作目录可见。普通主副卡不进入 Bot 会话；群成员不会因同一设备的当前人设组合而改变身份。团队协调工具按成员身份保留，普通聊天的五项常驻工具保持原机制。

实现使用正式 npm `ds-bot@0.1.5`（Apache-2.0），原始文件保存在 `vendor/ds-bot`，文件哈希和发行完整性见 `upstream.json`。适配层提供模式切换、角色卡创建成员及既有技能和工具衔接；上游的独立会话、消息、群聊与记忆机制保留。核心固定为 `0.2.1-alpha.1`。更新通过本项目的程序部署，不在团队页面升级 DSH 核心。

客户端由 `node team/build-client.mjs` 生成，生成前校验原始客户端 SHA256 和每个适配位置。不要手工修改生成的 `client.js` 或上游文件。
