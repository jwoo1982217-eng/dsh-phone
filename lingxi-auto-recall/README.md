# 灵犀本机知识库自动召回

独立 Cordis 插件，在主代理回答前直接读取原 DSH Knowledge Workbench 的内存快照，按当前提问相关性选取最多 3 段、本体最多 2400 字符的笔记参考。没有额外网络请求、索引副本或写入任务。原历史记忆、Noema 与自动召回范围均不改变。

默认关闭；首次部署按用户明确要求在本设备的 `knowledge/lingxi-auto-recall.json` 启用。设置页 `/lingxi-recall` 可立即开关，无需重启。插件配置和源文件位于 `$DSH_HOME/extensions/lingxi-auto-recall/`；正式 profile 仅追加本插件入口，当前安装不会覆盖核心或已有插件源码。

来源含标题、虚拟笔记路径、修订号、修改时间和行号；笔记始终标记为参考材料。问候、无关问题、回收站笔记不带入；QQ/云端入口和子代理不参与。取消仍保留原语义；异常不阻断正常对话；禁用或下一轮无命中时，新的运行上下文不再带入旧参考，同时保留其他运行上下文和原权限内容。已有聊天记录中曾经带入的资料不会被本开关删除。

兼容 alpha.1 在 pre-step 前已组装上下文的时序，使用该设备实际加载的官方 `createUserMessage` 合并本轮 runtime-context 快照。所有已有 section 保留。新插件需由正常后端重启加载；维护者先确认无运行任务，不关闭原生界面或清除资料。

测试应覆盖真实固定 SDK AgentLoop 的请求入口，不能把纯函数挑选成功当成已自动带入模型。部署前后保留实际 profile 备份及 SHA，配置并发变化拒绝覆盖。新 APK/核心升级仍按手机端维护契约验收实际加载。
