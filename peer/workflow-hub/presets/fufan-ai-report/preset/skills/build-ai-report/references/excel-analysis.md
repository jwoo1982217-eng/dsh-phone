# Excel 数据分析规则

本文件用于输入工作簿、字段或分析问题变化时的深度剖析。完成剖析后，只把统计摘要、口径和聚合结果写入报告，不复制完整原始明细。

## 1. 识别真实数据区域

按以下顺序判断：

1. 枚举工作表、可见性、最大行列和非空单元格范围。
2. 排除纯封面、说明、图表和打印页；但保留其中的数据来源、单位和口径文字。
3. 在候选数据表中寻找连续矩形区域，检查空白分隔行、重复标题和尾部注释。
4. 用“非空列数、字段名可解释性、后续行类型一致性”共同判断表头行。
5. 记录实际数据起止行、表头行、有效记录数和被排除行数。

不要仅依赖 `max_row`/`max_column`：历史格式、已删除内容和整列样式可能让有效区域虚高。

## 2. 建立字段画像

对每列至少计算：

- 原始列名与规范化列名；
- 推断类型：文本、整数、小数、布尔、日期时间、分类、ID、公式或混合；
- 非空数、缺失数、缺失率和唯一值数；
- 数值最小值、最大值、中位数和异常数量；
- 日期最早值、最晚值和粒度；
- 前若干高频值及其占比；
- 单位、币种、百分比、对数或“万元/百万”等显示线索。

类型判断优先使用单元格真实类型，再结合数字格式和列名。Excel 日期可能以序列号存储；百分比单元格的底层值通常为 `0～1`，不能直接当 `0～100`。

## 3. 识别字段角色

- **ID**：高唯一性，用于去重或追踪，不适合直接求和。
- **维度**：地区、机构、产品、类别等离散字段，用于分组。
- **度量**：收入、数量、时长、成本等可计算字段。
- **时间**：日期、月份、季度、年度；先明确时区和完整周期。
- **层级**：国家→省→城市、品类→子品类等父子结构。
- **状态**：开放/受控/关闭、已发布/待发布等有限枚举。
- **备注**：解释性文本，默认不进入定量聚合。

高唯一文本列可能是名称或 ID，不要因为它是文本就当分类维度。

## 4. 处理公式

必要时分别以 `data_only=False` 和 `data_only=True` 读取：

- 前者用于确认公式表达式和覆盖范围；
- 后者用于读取工作簿中已有的缓存值。

若缓存为空、明显过期或公式依赖外部链接：

1. 不把公式字符串当数值；
2. 不让 `openpyxl` 承担公式计算，它不会重算 Excel 公式；
3. 优先从可验证的原始列重新计算简单指标；
4. 无法可靠重算时排除该指标并报告限制。

## 5. 清洗决策

### 缺失值

分别保留：缺失、零、不适用、未知。只有业务规则明确时才填补缺失值，并记录填补方法及影响记录数。

### 重复记录

先定义业务主键，再区分：

- 完全重复行；
- 同一 ID 的重复快照；
- 多对多关系导致的合理重复；
- 一条业务记录在多个分类中的重复参与。

没有可靠主键时，只报告疑似重复，不自动删除。

### 合计与小计

识别包含“合计、总计、小计、Subtotal、Total”的行以及公式求和行。明细聚合时排除这些行，避免二次累计。

### 异常值

检查负数、不可能日期、单位跳变、极端数量级和分类拼写差异。异常值不等于错误；先结合业务含义决定保留、修正或排除。

## 6. 建立可追溯聚合

每个结论都保存以下口径：

```text
分析问题：受控访问比例如何变化？
数据区域：开放性趋势!A2:E4
维度：时期
度量：受控访问记录数
分母：该时期开放性已知的记录数
筛选：排除开放性缺失记录
计算：受控访问记录数 / 已知开放性记录数
舍入：页面显示整数百分比，内部保留原始小数
校验：每个时期三类占比未舍入值之和为 1
```

聚合后至少核对：

- 分组记录数之和是否等于纳入记录数；
- Top N 加 Other 是否等于总体；
- 比例的分子是否为分母子集；
- 时间序列是否漏掉无记录周期；
- 多标签记录采用“记录数”还是“参与次数”，标题必须准确；
- 单位换算是否在所有图、标题和 tooltip 中一致。

## 7. 常用分析问题

- **发生了什么**：总量、趋势、同比/环比、峰值和拐点。
- **谁贡献最多**：排名、份额、集中度和长尾。
- **由什么构成**：整体构成、组内构成和结构迁移。
- **差异在哪里**：组间比较、前后变化和分布差异。
- **是否相关**：两个连续度量的关系、异常点和分群；不把相关写成因果。
- **如何流动**：阶段转化、状态迁移或来源去向。

先选择用户真正关心的问题，再决定是否需要图表。不能形成明确问题的字段，不应为了凑图而展示。
