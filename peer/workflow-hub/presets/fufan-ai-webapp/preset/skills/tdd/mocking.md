# 什么时候使用 Mock

只在系统边界使用 Mock：

- 外部 HTTP API。
- 第三方账号或付费服务。
- 生产数据库。
- 时间和随机数。
- 无法在测试环境稳定提供的文件系统边界。

不要 Mock：

- 自己控制的模块和类。
- 页面内部状态管理。
- 组件之间的普通调用。
- GridStack、业务映射等可以真实运行的本地依赖。

若外部服务会让测试不稳定，应在应用边界封装语义明确的小接口，例如 `loadWorkspace()`，测试时替换该边界，而不是创建一个根据 URL 分支的万能 `fetch` Mock。

本案例的工作区 JSON 是本地确定性输入，不需要 Mock；浏览器测试应真实请求 `/data/creator-workspace.json`。
