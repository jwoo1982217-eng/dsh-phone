# 手机与家里的电脑

手机 DSH 保留独立运行。切换到电脑后，对话、工作区、文件和 AI 工具都来自电脑；电脑可以调用自己的 API，也可以经加密连接调用手机上的模型网关。两端无需在同一 Wi-Fi。

## 电脑安装

当前适配 DSH `0.2.1-alpha.1`。首次安装和从旧版升级请按 [电脑版安装说明](../desktop/README.md)，使用锁定的桌面运行时，不复制手机数据库：

```sh
npx --yes pnpm@10.34.6 --dir desktop-runtime install --frozen-lockfile
node scripts/install-desktop.mjs
node scripts/start-desktop.mjs
```

安装器保留 profile 的其他插件，加入 Jet Hub、ChatGPT 会员和 `dsh-peer`。启动后在同一已登录浏览器打开 `http://127.0.0.1:3080/phone-peer`。安装器不会重启正在运行的 DSH。

## 没有域名或服务器：临时外网入口

在家里的电脑安装 [Cloudflare 官方 cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)，然后保持下面的程序运行：

```sh
node scripts/start-home-relay.mjs
```

它只将本机的密文中继发布到外网。终端会输出 `wss://随机地址.trycloudflare.com/relay`；在电脑设备连接页粘贴地址，生成连接链接。手机顶部「电脑」粘贴连接链接，点「连接并打开电脑」，连接成功后自动进入电脑页面。远程页面标出电脑名称，可以返回手机本机。

[Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) 无需账号或域名，但属于临时通道，重启地址会变化，需要重新连接。实际可用性取决于两端网络和 Cloudflare；长期使用建议固定中继域名。电脑保持开机、不休眠，桌面 DSH 和中继都要运行；手机网关也需要保活。

## 固定中继

在服务器安装 Node.js 22.19+ 与 `ws`，运行本项目的中继：

```sh
DSH_RELAY_HOST=127.0.0.1 DSH_RELAY_PORT=8789 node peer/relay.mjs
```

用 TLS 反向代理将 `/relay` 转发至 `127.0.0.1:8789/relay`，启用 WebSocket upgrade；两端填 `wss://你的域名/relay`。健康检查为 `/health`。不要向公网暴露电脑 DSH 的 3080 或手机网关的 8326。

## API 配置与手机网关

手机「服务 → 设备连接 → 预览同步到电脑」同步普通模型配置里的 API 地址、Key、请求头、模型与参数，支持 `llm-pi-ai` 和 `llm-deepseek`。本机 loopback 地址、缺少凭据的接口会跳过。预览不显示密钥；同名配置可以保留或更新。写入失败会尝试恢复本次配置，遇到电脑并发修改会提示重新预览。自动同步默认关闭，启用后仅添加新接口，不覆盖电脑同名配置。

网页登录账号留在手机，电脑模型菜单选择「手机模型网关」。本机兼容地址是 `http://127.0.0.1:8327/v1`，支持模型目录、流式聊天、函数工具与声明支持的图片输入；由手机现有网关处理账号续期和供应商协议。关闭「允许已配对电脑调用手机模型网关」后，新请求被拒绝。普通 API 成功同步后，电脑可独立使用，不依赖手机在线。

手机网关使用手机供应商的默认推理设置，桌面入口不提供单独的推理等级覆盖。普通 API 同步后使用桌面原有适配器设置。

模型报错会保留手机供应商的错误码和说明，连接失败也会提示检查两端服务；收到部分回答后再出错，不会记作成功。电脑会话选择「手机模型网关」中的模型时，请保持手机 DSH 与网络可用。使用电脑本机已授权的模型，可在模型菜单中选择该电脑自己的提供商。

这不是两套离线会话、文件、记忆数据库的自动合并。远程模式直接操作电脑同一实例，手机本机和电脑的文件路径各自保留。QQ 使用现有插件；飞书、微信需要各自的消息适配插件与账号配置。

## 连接与权限

连接链接含设备间的随机密钥，应只交给自己的手机。AES-256-GCM 按方向派生密钥，每次连接双方交换新的随机挑战后才接收业务数据，防止篡改、重放和跨重启回放。中继只看到密文、房间标识与连接状态。连接信息存放在 DSH credentials 服务，界面只有主动显示/复制时才输出。

配对意味着授权手机使用电脑 DSH 界面及其已有权限，包括配置和工作区操作。电脑执行仍遵守 DSH 自身的审批和工具规则；手机不绕过这些规则。浏览器代理端口只绑定 loopback，检查 Host/Origin；中继无任意目标地址转发接口。

断线不会自动重发任务或模型请求；已经交给电脑的任务可能仍在运行。重连后查看同一会话确认结果，避免重复操作。解除配对会关闭通道；电脑重新生成连接链接会撤销旧链接。

## 验证

```sh
node --test peer/*.test.mjs
```

测试使用本机中继、临时配置与模拟模型，不读取真实账号或发送收费请求。公网网络、实际手机后台存活和真实账号调用需要配对后验证。

首次进入会优先复用手机已有的同版界面资源（带内容哈希的文件与相同修订的 SDK），电脑的会话和 API 请求仍经加密连接；其他 JavaScript/CSS 资源会压缩传输，并通过有上限的并行分块传输降低外网延迟。页面完成加载后才显示“电脑模式”；正在加载和失败会分别显示状态，不自动重发任务。顶部“电脑／手机”直接切换，连接设置与 API 同步在“服务 → 设备连接”。旧配对码仍可使用，原有配对保留。

电脑自己的 ChatGPT 会员与手机共享模型可能同名。共享模型在模型列表和当前模型名称前显示“手机网关 · ”，直接选“ChatGPT 会员”分组内没有此前缀的模型，使用电脑本机授权；新对话默认模型和已有会话选择仍分别保留，不按显示名称猜测或自动改路由。
