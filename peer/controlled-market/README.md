# 插件市场与备份后试装

两端入口均为 **设置 → 插件市场**。使用与 [dsh-market](https://github.com/dsh-market/dsh-market) 相同的 [社区目录](https://awesome-dsh-plugin.com/)，支持搜索、分类、分页、源码链接和目录刷新。

## 手机试装

手机 0.1.36 起，可以主动勾选 **允许试装未验证插件**，再点插件卡片中的 **备份后试装到手机**。默认关闭；关闭后仅浏览。第三方目录的兼容或审核标签不会自动打开开关，本项目尚无标为 Android 已验证的外部社区版本。

NPM 包固定到目录提供的具体版本；只有 GitHub 来源的插件会先解析并固定完整提交 SHA。读取真实发布清单后，明确排除 Android/arm64、SDK 版本冲突、无有效插件入口的来源会说明原因。核心 SDK、账号、QQ、Noema、设备连接等已内置适配组件不允许覆盖为社区版。

确认试装后，APK 的独立原生服务检查当前 AI 任务；有任务运行时拒绝安装，需任务结束后重试。随后停止本机服务、自动保存安装前环境，再安装已确认的固定内容。安装使用 APK 内置 Node 与 pnpm 10.34.6，放在 profile 的独立目录，复用内置 SDK，并保留依赖锁和下载摘要；不执行安装生命周期脚本或 pnpmfile。若源码还需要额外构建环境，将提示缺少可运行发布产物，不能保证所有社区仓库都能直接运行。

下载、校验或安装失败会恢复安装前环境；启用后不合适、界面异常或无法启动时，从 **服务 → 备份与恢复 → 恢复最近备份** 撤回。原生恢复不依赖网页能否启动，保留最新对话和登录凭据。备份在应用私有目录，卸载会删除。详见 [恢复说明](../../docs/phone-recovery.md)。第三方插件是可执行代码，可访问 DSH 获得的文件和账号数据；备份解决环境回滚，不能隔离或撤销插件向外发送的数据。

## 电脑目标

电脑明确显示 **当前目标：这台电脑**。每个插件使用信息卡片展示名称、版本、分类、GitHub 收藏数、简介和作者，点击「详情」查看来源与安装目标。拥有固定 NPM 发布版本的插件可直接点击「一键安装到电脑」：先检查真实发布清单、当前平台与 SDK，再在页面确认下载和启用，无需打开终端。安装结果、已安装/停用及需要重启状态显示在卡片中；缺少可运行发布版本的项目仍可查看源码。手机市场中的 **查看已连接电脑的市场** 进入电脑服务，要求设备已连接并更新电脑程序。手机原生备份与恢复只管理手机本机，不能用来回滚电脑环境。

## 目录与安装边界

目录和发布清单只通过固定公共 HTTPS 来源读取，不发送本机凭据，不执行目录中的安装文本、HTML、脚本或构建命令。源码链接限定为 HTTPS GitHub 仓库，内容用纯文本展示。默认目录上限 16 MiB/25000 项，发布清单 2 MiB，单个下载包 64 MiB。失败时明确标记缓存时间。

试装计划通过已认证的本机管理接口产生，10 分钟内单次使用；插件名、版本、提交和下载地址由服务端解析，页面不能指定 shell 命令或改变安装目标。未来 Android 实测过的外部插件可以另行标注；「可试装」始终不等于「已验证」。
