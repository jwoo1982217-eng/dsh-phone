# Agent 主副人设卡

手机和电脑版均在「设置 → Agent 人设」使用；也可从已登录的 DSH 页面打开 `/agent-cards`。手机技能中心提供同一入口。

1. 点击「新增主卡」，填写基础角色与工作约定，保存。
2. 点击「新增副卡」，填写编程、写作或其他专项工作方式，保存。
3. 在「当前组合」选择一张主卡及需要的副卡，点击「应用当前组合」。可只使用副卡，也可停用全部卡片。
4. 填写组合名称，点击「保存为组合」。以后点击组合的「一键应用」即可切换。修改卡片正文会更新引用它的所有组合；组合保存与应用是两个独立操作。

最多保存 64 张卡、32 个组合，同时使用 1 张主卡和 8 张副卡。单卡最多 32 KiB，当前组合正文最多 128 KiB，卡库文件最多 512 KiB。正文会计入模型输入，建议保持简明。

这些配置作用于当前设备上的普通主 Agent，不覆盖 QQ 人设或子智能体自己的角色。切换从下一次模型请求生效；正在进行的请求和既有聊天内容不会重写。需要完全更换角色背景时，应用后新建对话。权限、工具、系统上下文和已有 Agent 预设保持原有机制。

电脑模式中的人设页来自电脑；手机本机模式中的人设页来自手机。卡库各自保存在本机 DSH 用户配置中，不自动覆盖另一端。使用「导出卡库与组合」生成 JSON，在另一端导入可保留正文和组合；导入会生成新标识，不改当前选择、不自动启用。Markdown/TXT 可按所选类型导入为一张卡。手机导出由 Android 系统文件保存器选择位置，不申请额外存储权限。导出不包含模型凭据，正文内自行填写的私人信息仍会包含，分享前请检查。

升级时已有手机提示卡的正文、修改和启用状态迁移到副卡库；已迁移条目不会重复导入或重复注入。新技能包中的提示卡在下次打开人设页时加入卡库，保持停用。旧技能中心提示卡开关只继续管理 QQ；DSH 主 Agent 统一在人设页切换。

实现位于 `peer/agent-cards/`，使用官方 `settings.section` 插槽挂载页面、经过认证且限制回环来源的 RPC 保存配置，并通过真实 `systemPrompt` 变量加入下一次请求的上下文。卡片正文中的 `{{…}}` 保持字面文本，不作为未知模板变量解析。存储失败或并发版本冲突不会发布半份人设配置。
