# 查记忆与技能经验传递

DSH 设置新增“查记忆”和“技能与经验传递”。三端本地运行 BGE-small-zh-v1.5 固定 q8/CLS 模型；安卓用单线程 WASM，模型随程序提供，无需上传聊天。索引包含本机记忆 Markdown、导入的经验候选与本机 DSH 会话；首次点击更新索引，后续增量计算。电脑可复用已部署的 KB Lite 索引。

任一设备在设备页选择本机局域网地址，生成15分钟有效的连接链接；在另一台设备的同页粘贴。电脑、手机和平板均可发起连接，安卓设备之间可直接互传。连接保存于各自 DSH_HOME/knowledge，电脑支持最多10台设备。两端保持DSH运行，选择目标、勾选技能/经验、发送；接收端预览后选择保留或带备份替换同名项。解除连接立即停止本端通道。当前入口按局域网连接设计，跨公网需要另行配置可用的加密中继。

传输复用现有 PeerTunnel 的 AES-GCM 双向密文、重连挑战和防重放协议，使用独立房间和发起端3082端口；不改变原有远程电脑/模型网关配对。接口只传技能与经验，不提供命令执行、凭据同步或远程文件任意读写。失败不自动重发提交，可查看状态后重新选择发送。

可选择 DSH / Mac Codex 的独立技能目录、已导入技能包中的技能、共享单技能与验证经验。技能目录内资源逐文件SHA256校验，拒绝符号链接、危险路径和检测到的真实凭据；导入到接收端DSH技能库，不执行脚本。跨技能目录引用、外部模型、服务、原生依赖与平台绝对路径需在目标环境另行适配；传递成功仅证明文件导入，不能保证任意脚本可跨平台运行。单次最多50项/128MB/50000资源，复杂大包请分批选择。

经验只传方法、适用条件、不适用条件与来源/证据摘要，原始私聊和证据文件不随包传。源端批准状态保留为来源记录，接收端写入可检索候选，不写入接收端的批准指针。收到的候选可作为本机任务参考，实际正常/边界/失败恢复验证仍走既有经验流程。

`node --test peer/knowledge-link/knowledge.test.mjs` 检验实际加密通道、两个目标、反向传递、同名保留与替换、并发目标变化、故障回退及恶意包拒绝。真实设备证据另记，测试通过不等于手机效果验收。

手机版若启用了“只用已选技能”模式，新入口只登记本次请求的记忆检索技能和经本入口明确导入的技能，保留原有选择，不恢复整库。QQ 会话不能通过新增宿主工具读取本机历史。
