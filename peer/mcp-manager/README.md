# MCP、模型调度与内置浏览器

在「设置 → MCP 服务」查看连接、添加服务和导出排查记录。支持本机命令（stdio）、HTTP 和 SSE；手机可直接连接本机 MT，电脑版通过自己的 ADB 转发连接 MT。服务接入成功才替换旧配置，凭据通过 DSH 凭据库保存，页面与导出记录不回显凭据值。MCP 是通信协议，模型推理及第三方服务仍可能计费。

手机原生入口为「服务 → 内置浏览器」。DSH 的浏览器工具直接使用自己的 Android WebView 服务；电脑版接入自己的 Chrome 浏览器服务。与 Operit 的对照参考其[官方项目](https://github.com/AAswordman/Operit)，本实现不调用 Operit，也未复制它的软件源码。

| 手机操作 | 继续使用 DSH 自己的无障碍、截图、Shizuku 日志与既有三种会话权限；不增加一个“全应用授权”开关。系统权限和受保护窗口仍受 Android 限制。 |

这里已补齐核心工具连接，尚未达到 Operit 整个产品的完全功能等价。浏览器下载、文件上传、书签与用户脚本，内嵌完整 Linux 发行版及 SSH/SFTP 管理，本地 MNN/GGUF 模型、语音与桌面角色系统，都没有在本批实现。现有手机工具并不等于这些附加功能已安装。

在新 DSH 窗口可以说：“探测允许目录里适合这件事的模型，再分配任务；先完成一个小任务并验收。”主代理调用 `mcp__router__models/probe/dispatch/reuse/evidence/feedback`。简单文字任务默认用 `answer`，需要工具或持续上下文才用 `agent`；相关后续任务可送回原子代理。真实失败会隔离本窗口的对应能力，成功反馈和强制重测都不能解除失败隔离；你在管理页点击“恢复探针资格”后，还要重新测试，成功才重新参与派单。验收记录不写成全局规则。

探针一次最多三条线路、每条两个小样例；当前窗口调度最多四十次推理，每个派出的子代理最多八次。重启不会重置已有子代理的计数。管理页可隔离窗口或手动重置窗口预算；子代理八次上限不随之重置。这些限制作用于调度产生的请求，不包含主代理自身的全部对话开销。

两个小样例仅能筛选候选，不能证明模型在所有任务上可靠。本轮有真实推理、原生派单、重启后复用与用量证据，没有逐一测试全部模型。价格未配置或缓存用量不完整时显示“费用未知”，以 token 用量做粗略排序；只有候选单价都有出处且币种一致才按估计金额比较。原生子代理会加载环境和已有上下文，复用也可能增加输入用量，因此不能保证必然省钱。目录指纹只检测线路元数据变化，不证明中转上游的模型身份。

浏览器标签归属由实际会话与项目计算，模型不能传入另一个窗口的归属；工具浏览器与 DSH 登录页面使用不同存储目录。工具浏览器各窗口仍共用该浏览器的登录存储，标签隔离不等于独立 Cookie 容器。页面内容、工具结果与模型验收记录都作为带来源的材料；不接受 MCP 服务器把自身指令直接加入全局提示。

点击、输入和外部写入沿用聊天已有的完全权限模式。完整文件权限与同 UID 插件仍可以直接修改磁盘，这是应用层隔离，不能称作恶意插件的操作系统沙箱。停用共享记忆也不会清除已有聊天上下文；排查完请新开窗口。首次拒绝行为的起因尚未证实，不能据此认定是官方插件导致。

手机升级需要同时更新 APK 和资源版本，保留账号、对话、技能、人设与配置。打包检查两份资源包中的模块依赖及隔离代码；桌面安装器也携带这两个模块。安装前等待进行中的任务结束。

## 媒体等 stdio 扩展的覆盖升级

独立服务和完整依赖放在 `$DSH_HOME/extensions/mcp/<服务>/`，在「MCP 服务」中配置启动命令 `node`，参数例如 `["$DSH_HOME/extensions/mcp/media/server.mjs"]`，启动目录 `$DSH_HOME/extensions/mcp/media`。仅展开路径开头的 `$DSH_HOME` 或 `${DSH_HOME}`；不会执行 shell 替换。Android 内置 Node 每次按当前 APK 解析，旧配置里指向本应用 `/data/app/.../libnode.so` 的绝对路径也在启动时解析为当前 Node；Termux 或其他应用的 Node 保持原命令。凭据仍留在已有凭据库，环境变量继续按明确保存的内容传递。

安卓更新在替换程序树和内置 profile 包前扫描已保存 stdio 的命令、文件参数和启动目录。新包未包含的独立目录被复制到持久扩展目录，配置经原子写入改为 `$DSH_HOME` 路径，旧配置留在私有 `storage/mcp-manager/upgrade-backups`。自装 profile 包本来会保留，继续原位置。只复制闭合目录，目录外符号链接、特殊文件、超过 512 MB/20000 项或无法独立搬运的单文件补丁会中止替换，保留原程序与连接配置，供整理为完整服务后重试。

这不自动移植直接修改 DSH 核心、SDK、渲染器的补丁。那类修改需要原补丁代码和具体错误才能适配；工具依赖的外部运行时、绝对路径和远程 API 也要单独核对。只有可识别的独立服务目录属于自动迁移范围，未登记的文件、嵌在 `bash -c` 字符串里的路径不会被自动发现。覆盖升级保留用户目录；卸载、清除数据及更换不同包名仍不属于保留范围。

Android 内置 Node 的 `LD_LIBRARY_PATH` 也在每次启动 stdio 时按 `files/bin/node` 的真实目标解析。即便旧凭据 env 中存着已删除的本应用 `/data/app/.../lib/arm64`，子进程也使用当前 APK 的库目录，并保留其他自定义库目录、环境变量、请求头、启动参数和 cwd；持久凭据原件不重写。外部 Termux / 其他应用运行时和桌面环境保持原配置。此修复针对动态链接器加载失败，不等同于已处理远程 HTTP 的 `fetch failed`；网络、接口和代理失败需要单独证据。
# 内置媒体生成

`media` 通过真实本机 MCP 传输提供 `generate_image`、`generate_video`、`generate_audio`、`list_models`、`result`。升级旧配置时只补缺失的内置服务，保留已有同名外部媒体服务及其他配置。图片/视频实时读取账号设置中的 Agnes 接口和凭据引用；没有作者默认密钥，凭据不复制进源码或任务记录。

图片使用 `/v1/images/generations`；视频使用 `/v1/videos` 创建和 `/agnesapi?video_id=…&model_name=…` 查询。视频ID和生成结果保存于 `$DSH_HOME/storage/media/jobs`，重启只查询已有任务，不重新提交。图片生成允许330秒，视频提交与查询分开；网络失败显示HTTP、DNS或连接错误。音频使用macOS系统朗读/Android系统TextToSpeech，产出WAV，只代表语音合成；音乐与音色克隆需要另接相应服务。参考图目前接受公网HTTPS地址。

设置页可查看、播放、保存结果。文件下载沿用DSH网页认证并支持视频Range请求。媒体生成沿用当前聊天的完全权限，模型查询/结果读取只允许自己的项目窗口；已认证的人类设置页可查询已有各窗口任务。费用保持未知，不将供应商限时免费写成永久规则。
