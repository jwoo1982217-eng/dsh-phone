# MCP、模型调度与内置浏览器

在「设置 → MCP 服务」查看连接、添加服务和导出排查记录。支持本机命令（stdio）、HTTP 和 SSE；手机可直接连接本机 MT，电脑版通过自己的 ADB 转发连接 MT。服务接入成功才替换旧配置，凭据通过 DSH 凭据库保存，页面与导出记录不回显凭据值。MCP 是通信协议，模型推理及第三方服务仍可能计费。

手机原生入口为「服务 → 内置浏览器」。DSH 的浏览器工具直接使用自己的 Android WebView 服务；电脑版接入自己的 Chrome 浏览器服务。与 Operit 的对照参考其[官方项目](https://github.com/AAswordman/Operit)，本实现不调用 Operit，也未复制它的软件源码。

| 能力 | 本批状态与实际边界 |
| --- | --- |
| 浏览器 | 打开、读取正文和元素、中文输入、点击、按键、截图、滚动、前进、后退、刷新、关闭；手机与桌面均经过真实工具执行验证。 |
| 手机操作 | 继续使用 DSH 自己的无障碍、截图、Shizuku 日志与既有三种会话权限；不增加一个“全应用授权”开关。系统权限和受保护窗口仍受 Android 限制。 |
| 文件与命令 | 保留自带文件工具、Bash 与已有 Termux 接口；当前设备已连接无障碍和 Shizuku，Termux 传输权限可用。软件包与环境能力以具体命令结果为准。 |
| MCP | 可管理外部工具服务；本机 MT 已接入，电脑 MT 需要手机 ADB 在线和 MT 服务运行。 |
| 模型派单 | 独立程序执行能力探针、排序、文字子任务、原生子代理派单与上下文复用；结果和用量按项目、窗口保存。 |
| 工作流与技能 | 保留现有 Preset 广场、工作流、技能导入和主副人设卡；本批未把第三方工作流改写成人设。 |
| 记忆隔离 | Noema 保持停用；已安装的隔离入口继续提供暂停、来源、隔离与回退。本批程序和浏览器结果不自动写入共享记忆或人设。 |

这里已补齐核心工具连接，尚未达到 Operit 整个产品的完全功能等价。浏览器下载、文件上传、书签与用户脚本，内嵌完整 Linux 发行版及 SSH/SFTP 管理，本地 MNN/GGUF 模型、语音与桌面角色系统，都没有在本批实现。现有手机工具并不等于这些附加功能已安装。

在新 DSH 窗口可以说：“探测允许目录里适合这件事的模型，再分配任务；先完成一个小任务并验收。”主代理调用 `mcp__router__models/probe/dispatch/reuse/evidence/feedback`。简单文字任务默认用 `answer`，需要工具或持续上下文才用 `agent`；相关后续任务可送回原子代理。真实失败会隔离本窗口的对应能力，成功反馈和强制重测都不能解除失败隔离；你在管理页点击“恢复探针资格”后，还要重新测试，成功才重新参与派单。验收记录不写成全局规则。

探针一次最多三条线路、每条两个小样例；当前窗口调度最多四十次推理，每个派出的子代理最多八次。重启不会重置已有子代理的计数。管理页可隔离窗口或手动重置窗口预算；子代理八次上限不随之重置。这些限制作用于调度产生的请求，不包含主代理自身的全部对话开销。

两个小样例仅能筛选候选，不能证明模型在所有任务上可靠。本轮有真实推理、原生派单、重启后复用与用量证据，没有逐一测试全部模型。价格未配置或缓存用量不完整时显示“费用未知”，以 token 用量做粗略排序；只有候选单价都有出处且币种一致才按估计金额比较。原生子代理会加载环境和已有上下文，复用也可能增加输入用量，因此不能保证必然省钱。目录指纹只检测线路元数据变化，不证明中转上游的模型身份。

浏览器标签归属由实际会话与项目计算，模型不能传入另一个窗口的归属；工具浏览器与 DSH 登录页面使用不同存储目录。工具浏览器各窗口仍共用该浏览器的登录存储，标签隔离不等于独立 Cookie 容器。页面内容、工具结果与模型验收记录都作为带来源的材料；不接受 MCP 服务器把自身指令直接加入全局提示。

点击、输入和外部写入沿用聊天已有的完全权限模式。完整文件权限与同 UID 插件仍可以直接修改磁盘，这是应用层隔离，不能称作恶意插件的操作系统沙箱。停用共享记忆也不会清除已有聊天上下文；排查完请新开窗口。首次拒绝行为的起因尚未证实，不能据此认定是官方插件导致。

手机升级需要同时更新 APK 和资源版本，保留账号、对话、技能、人设与配置。打包检查两份资源包中的模块依赖及隔离代码；桌面安装器也携带这两个模块。安装前等待进行中的任务结束。
