# 手机长会话上下文恢复

适用于手机独立运行的 DSH SDK `0.2.1-alpha.1`。来源为桌面 `d811a5b` 的上下文恢复改进，已针对手机实际 SDK 和私有运行副本验证；不升级核心版本或改变账号、用户选择及权限。

## 行为

- 压缩使用当前步骤已经组装的模型选择；手动 `/compact` 优先读取尚未消费的用户选择，显式摘要模型配置仍优先。切模型时不继承旧适配器的自动输出预算。
- 在真实模型容量内预留输出及余量，把超长历史分批整理再合并。工具调用和结果成组，超长单条内容完整分片。分批请求不执行工具；保留附件引用，不假称已读附件内容。
- 仅明确上下文超限才继续缩小输入；每轮最多64次新请求。鉴权、额度、截断、取消、空输出或缺少结束标记均保留原历史，不以重复相同请求恢复。
- 沿用 SDK 锁、选中范围稳定性与提交事务。摘要完成后恢复前须检查文件与未完成任务，不自动重放不确定的编辑或外部操作。

存在任务工作目录且设置 `DSH_HOME` 时，恢复记录存于 `DSH_HOME/storage/context-recovery/<会话ID的SHA256>.json`。目录0700、文件0600，原子写入；只复用来源请求、模型和预算一致的成功分段。损坏或身份不匹配的记录保持原样。`prepared` 只代表摘要生成完成，实际提交必须同时核对会话内 `compaction/summary` 和成功 `compaction/end`。

## 源码、分发与私有副本

维护源在 `runtime/overlays/@deepseek-ai/dsh-compaction-basic/lib/` 的 `index.js` 与四个 `summary-*.mjs`。现有 `scripts/build-assets.py` 复制整个覆盖目录到部署模块树，因此新增相对导入也进入下次分发，不能只复制 index.js。

用户安装社区私有 SDK 后，活动入口可能来自 profile 的 `.dsh-purge-runtime/<代次>/node_modules`。升级必须依照[手机升级契约](phone-upgrade-contract.md)，从当前 owner、profile bundles 与正式日志核对活动代次；保留该副本对其他 SDK 模块的定制。只在版本和旧SHA已验证时同步上述五文件，冲突或未知版本先重新适配；非活动旧代次留作恢复，不擅自覆盖。不得只更新 canonical 模块后宣称手机已加载新版。

0.2.10 / versionCode 115 将此覆盖纳入 APK 资源，`NodeRunner.ASSET_VERSION` 同步为115；资源重新生成后执行 clean 构建。此前对现有APK的定向程序更新保留为适配依据，发行包不含该设备的配置、凭据或私有 SDK 副本。

替换前检查当前任务、草稿与配置，备份原程序和需保留项目的校验；激活后核正式服务、工具发现、真实解析入口和代表性调用。回退只恢复本轮程序，保留用户随后生成的会话、配对、资料与续期凭据。

## 验证

```sh
node --import ./scripts/phone-test-imports.mjs --test scripts/compaction-recovery.test.mjs scripts/adaptive-compaction.test.mjs
```

可通过 `DSH_PHONE_TEST_MODULES` 指定实际活动私有 SDK 的 node_modules，对同一组 SDK 行为做验证。Android 应使用应用自己的 Node 和独立临时工作目录，勿改变正式会话。用例覆盖超长中日韩内容、切1M到32K、取消/损坏/失败保留、重启复用分段、真实SDK事务及压缩后读取随机文件并回传结果。

受控本地适配器验证执行与恢复机制，不代表所有云模型的摘要语义质量已验收；不发起付费调用或切换正式账号进行测试。

0.2.10 的覆盖升级还会在程序树替换前检查独立 OFM 插件：已装正式版本高于随包版本时保留整包，其他已知版本按随包更新；未知版本、身份或链接先停止，避免静默降级。此判断针对有独立更新器的 OFM，不代替其他用户扩展的冲突检查。
