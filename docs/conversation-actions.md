# 会话长按操作

本批源码支持：长按普通聊天中已落地的“我 / AI”消息，打开复制、分享、归入记忆、删除此条、多选 / 范围删除、局部删除文字。桌面浏览器可右键；代码块、链接和已有文字选区保留原操作。停止后已保存的 AI 消息也可操作，正在生成的临时片段不作为可删除记录。

- 单条和多选不连删后面的消息；范围删除需选两个真实消息端点并再次确认。
- 局部删字按内容块操作，支持 Unicode；仅删除，不接受新增文字。删空纯文字消息时转为删整条。
- 复制、分享、归入记忆使用正文，不自动带入隐藏思考、工具参数或附件文件。分享只打开系统选择器，不指定应用或收件人；正文上限 65536 字符。
- 归入记忆先展示完整正文、来源项目、会话/消息来源和共享范围，再显式确认。需要在设置启用 Noema；存入的是 `trust:user-submitted` 参考资料，不是已验证事实或批准方法。可能被其他窗口按现有共享召回设置检索；记忆管理中可独立删除。消息删除不会级联删除此前保存的独立记忆。
- 修改前必须没有运行中任务、维护任务或待处理输入。发现版本变化要求重新选择；保存失败会显示错误并阻止该会话继续发送，重新打开其他仍保留的消息菜单或顶部“消息管理”可重试保存（删空会话也可恢复），同一修改不重复追加。

## 真正影响后续上下文，而非仅隐藏 DOM

`conversation/edit` 是必需的追加事件，原事件不改写。核心重新折叠消息表面：移除选中消息、成对移除同一步骤的工具调用与结果，保留无关后续消息；局部改字保留消息身份和非文字内容。依赖被编辑内容的压缩摘要失效，无关摘要保留。旧历史相关的提供商 opaque replay 元数据被丢弃，不把旧签名/响应缓存带回编辑后的请求。图片 offload 的其他目标保留。

服务端从完整日志投影每一页，因此编辑标记不在当前页、重新打开聊天、向前分页时也不会显示回旧内容。已打开界面收到编辑事件后重建当前窗口，禁用陈旧目录摘要。确认保存须通过真实持久化 flush；失败不能报告成功。

**这是逻辑删除，不是安全擦除。** 原始审计日志、备份、独立记忆、项目文件及共享附件仍保留；已经执行的工具操作不会倒转。需要销毁整段聊天及专属附件时，仍使用原有“聊天记录”管理流程。导出原始审计材料可能包含原内容。

## 兼容与维护

仅针对当前固定 SDK `0.2.1-alpha.1` 适配；没有冒称升级为 rc.2。维护补丁在 `runtime/overlays`，UI 源码在 `peer/conversation-actions/client.js`；`node scripts/build-conversation-actions.mjs` 生成实际聊天/会话 bundle 内的两个浏览器辅助模块，资源构建自动执行。原生仅新增同源 `dsh-phone://conversation/share` chooser，不新增 Android 权限。

修改后的日志保留格式 v4，但带未知旧版不认识的**必需事件**。原有持久化入场校验会拒绝旧读者解释它，不允许忽略事件后悄悄恢复删除内容；直接绕过持久化校验调用旧 `Session.create(seed)` 的第三方代码不具备此保护。使用新功能后，不能简单降级到旧 APK/核心；回退 UI 时应保留新日志读者。未实际操作过的新日志不受影响。配对电脑若仍是旧端点，会明确报错，不静默退化成只删界面。

## 0.2.12 的旧私有 SDK 迁移

旧 community purge 插件可能把 Session、API、聊天界面固定到私有文件 URL。启动前只检查 `current.json` 指向的活动副本，对本版 10 个相关文件按已识别 SHA 定向升级；保留旧 rewind 行为、其他自定义文件和未活动快照。先校验全部输入和目标、备份旧字节，再写入；未知自定义字节或 SDK 版本不匹配时停止，不猜测覆盖。写入失败恢复已改文件，重复执行不追加修改。备份保留在用户目录的 `.phone-core-backups/private-sdk-*`，不是安全擦除。
