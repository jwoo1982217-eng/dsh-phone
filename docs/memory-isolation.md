# 记忆隔离与排查

当前两端已安装并验收：设置 → 记忆隔离与排查。发现异常时暂停学习与召回，选窗口查看来源、隔离或回退；人设可恢复到用户确认的基线。旧聊天仍在上下文，处理后开新窗口。

共享 Noema 停用检查位于服务管理器，覆盖设置页和模型入口；模型只保留状态与提交待审候选能力。导入器不直接接受材料。精进经验使用当前项目/窗口独立目录；主卡、权限及全局规则不受自动审批支持。实际文件变化和来源链路由排查页显示。

本次仅修改记忆模块、人设排查入口和精进技能，保留账号、原主卡、其他副卡与聊天。精进副卡新增隔离约定。源码及已安装运行目录均已更新；手机配置档可能持有独立插件副本，不能只更新公共 tree。Android app 目录别名必须验证设备/索引节点相同后统一，不能降低项目/窗口校验。

更新维护时使用 vendor/dsh-noema、peer/memory-isolation、peer/agent-cards 以及相应生成客户端；build-assets.py 会打包本仓库的修改。当前安装采用运行目录更新，未重建 APK；重新安装旧 APK 或覆盖旧插件可能还原旧代码。发布新安装包前须以这些修复源构建并验收。不要携带个人记忆、角色凭据或本地诊断记录打包。

可运行 peer/memory-isolation/*.test.mjs、scripts/memory-isolation.guard.test.mjs 以及已有人设测试。DSH 技能包使用最新版“验证式精进-窗口隔离版.zip”。应用层护栏不能代替系统权限隔离；完整文件权限可直接改写文件，来源真实性和语义异常仍需用户结合实际任务判断。
