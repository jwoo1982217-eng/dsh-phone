# 手机插件 2.5.7 适配

## 范围与来源

用户截图的“新公告 v2.5.7”和“插件可升级 2.5.7（当前2.5.3）”来自同一个 OFM 插件，不是两款插件。可信来源：[OFM v2.5.7](https://github.com/Ebony-Vinyl/dsh-our-free-model/releases/tag/v2.5.7)，2026-10-20 发布；下载同时校对 GitHub asset digest 和发行 SHA256SUMS。Wallpaper 仍为已安装的 1.3.3，不强行重装。

维护源码 `our-free-model/` 已升级2.5.7。使用官方新版作为基础，按语义保留旧维护源码和手机实际2.5.3的改动，包括共享 Jet Hub/accountPool、手机浏览器授权、响应式授权状态、受控重载与已有 SSE 行为；不把旧版整段函数覆盖新版签名或测速实现。

## 共同适配

- APK-owned兼容生成器区分2.5.1、2.5.3、2.5.7，不用同名旧函数hash推断新版本；未知版本/代码拒绝覆盖。
- 保留新版独立签名、托管更新提示与手动测速。正式账号或付费模型没有被测试脚本调用。
- 手机复用已有 CodeArts 后端时，不会执行 OFM 内嵌渠道包。因此共享 `vendor/dsh-codearts-auth/` 也移植独立请求传输：自有 undici Agent、保留环境代理、请求/取消和资源清理由本实例拥有，不经被其他插件改写的全局 fetch。聊天、登录/模型刷新与积分RPC显式绑定本实例，其他供应商逻辑不改。
- 插件升级只在完整安装指纹已识别时克隆原包，替换82个审阅文件；389个额外文件逐字保留。私有额外文件名和内容不进入公开迁移计划，只保存绑定的整体指纹。缺失插件不自动安装或启用；未知修改先停止整个升级。
