## 本轮跟进范围

1. ZCode：SSE 空闲超时、HTML/CDN 异常和业务错误分类，避免流永久挂起。
2. 账号池：空池刷新调度、新增账号唤醒、Raccoon/Loomy 切换，以及授权、额度、限流状态区分。
3. OpenAI 网关：Responses 接口、推理等级、模型映射与查询、工具图片输出、错误状态和 usage 兼容。
4. 同名模型聚合：渠道开关、优先使用更早到期余额及倍率策略、关闭渠道后目录更新；可见输出后不再切换重试。自动到期策略只采用有可靠探测的渠道，AutoClaw 和 ChatGPT 继续使用各自入口。
5. Token 账本：覆盖注册的适配器，按渠道、账号、模型查看用量、首 Token 延迟与生成速度；内存保留 500 条、日历史保留 90 天。
6. 模型能力与不可用模型：图片能力标记、基于真实失败证据摘除模型，以及恢复入口。
7. Gemini Code Assist：新增认证、账号、模型、额度和请求适配。
8. 推理循环恢复：没有可见输出且没有待处理用户输入时有限续接，默认最多两次。
9. 面板交互：供应商排序、Trae/LobsterAI 永久额度锁定、Buddy 成长与签到单位修正。排序同时支持电脑鼠标/键盘和手机触摸。
