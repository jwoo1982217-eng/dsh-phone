这是 2026-10-09 当前源码的独立公开快照。手机端保留原 0.1.58 源码；桌面端包含当时最新的本地源码及完整运行模块。来源提交及原项目许可证保留在 SOURCES.md。为排除旧历史中的内置 OAuth 信息，此次从干净初始提交发布，不推送旧标签与旧 Git 历史。

## Gemini 浏览器授权

公开版本不含默认 Google OAuth 客户端 ID 或客户端密钥。使用自己合法配置的 OAuth 客户端，在运行时环境设置：

- CMDC_PAK_GOOGLE_CLIENT_ID
- CMDC_PAK_GOOGLE_CLIENT_SECRET

不要在源码、日志或公开文件中填写实际值。环境缺失或为空时，授权会在启动监听与请求前给出缺项提示；补齐后使用原有授权流程。已有的授权码交换、state 校验、令牌续期和撤销流程保留。

桌面端将这两个变量设置在启动 Node 的环境中；手机源码构建者将其注入本机 Node 服务的私有启动环境。普通聊天和其他供应商可继续按原方式配置。仓库不内置任何使用者的账号、令牌、聊天、人设库或经验库。

发布过程未修改发布者原有本地工程、应用配置或 CNB 仓库。
