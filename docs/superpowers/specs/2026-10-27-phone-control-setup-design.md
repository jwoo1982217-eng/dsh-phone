# 手机控制开启与检查

用户已确认采用一个“开启并检查”入口，并补充：已有完全权限后，日常操作不得反复询问；联想无障碍反复显示“由受限设置控制”必须明确识别。

保持现有聊天三种权限及停止语义。原生页面检查界面控制、Shizuku 日志与 Termux 三个独立通道；某一项不可用不阻断其他项。按钮依次处理缺失的 Android 配置，返回页面后自动复查；已经完成的授权不重复请求。已有 Shizuku 授权时，通过只接受空参数的本应用恢复服务允许本应用受限设置并重连自己的无障碍；保留其他应用开关。首次点击开启自动恢复，后续仅在本机完全权限动作开始前尝试恢复，不重放已经提交的动作，停止及授权变化后不得继续。系统拒绝自动修复时退回公开设置入口，保留具体操作说明。取消或未修改配置后停留页面，不循环弹窗。

受限设置检查只查询本应用，能确认限制时优先打开本应用信息，说明“右上角菜单→允许受限设置→返回开启 DSH 手机操作”。无法读取状态时不声称已排除限制，保留该修复入口。不开全局安全例外，不伪造安装来源。

Shizuku 运行且已授权时直接复用，重连由既有 Binder 通道处理，不重新批准任务。服务未运行时打开 Shizuku 并说明启动；13.6 在可信 WLAN 下支持自动启动，但不承诺无配对、无网络或系统杀后台后总能自动启动。Termux 仅在缺少 RUN_COMMAND 权限时请求；外部调用的实际就绪以命令结果为准，不伪造探测成功。

维护包由已验收的 122 源码基线和 APK 资源准备，只纳入本次原生设置页面与辅助类，不混入规范工程已有官方 SDK 迁移 WIP。应用码递增至 123，运行资源仍为 122，不重解压用户 home。先验证旧界面缺陷，再验证新页面、缺权限/取消/恢复及权限模式不变。正式升级等待本机任务结束，保留系统授权基线、账号、会话和用户配置。
