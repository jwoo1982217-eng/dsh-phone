# 本轮范围与验收

用户要求参照已有模型路由界面重新实现，并同时交付完整知识库入口，电脑与 Android 都能使用。

路由：七策略、成员启用与排序、智能职责、明确选择的分类模型、权重/手工额度、首次输出超时、限流顺序、全部忙时等待、上下文、会话保持、组及成员展示、通配匹配、并发保存版本检查与诊断隐私。旧组 ID 不变；新组使用更长随机 ID。

知识库：独立侧边栏与设置入口；总览、笔记、MD/TXT 导入、分类/标签/状态、关键词与既有本机 BGE 混合检索、按既有范围选择历史、问答原文引用、草稿确认保存、真实链接/标签图谱、30 版历史、回收站、索引与日志。两端本机存储，不默认自动同步或放开自动记忆范围。

复用 `dsh-peer/knowledge-link`、现有浏览器授权、模型服务与设置槽。源码集成在两个仓库的 model-routing / knowledge-workbench 及安装打包脚本。手机升级登记和 Markdown 系统保存窗口另做原生适配，SDK 版本保持 Mac alpha.4 / Android alpha.1。

自动验证分别运行两个固定 SDK，另在真实运行中的 DSH 注入临时纯本机模型验证正常路由、429、部分输出失败和知识库引用，随后移除临时组和插件。付费模型调用为 0。安装包核签名、资源字节、SDK 和 native 库；界面及重启保留以本轮最终收据为准，不把测试数量等同于所有端到端结果。

验收日志与旧版备份保存在开发设备的本地证据目录，未随源码发布。源码内保留可重复执行的测试；含设备私密数据的备份不进入仓库。
