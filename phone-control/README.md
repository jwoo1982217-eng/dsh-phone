# DSH 手机操作与本机工具

手机 DSH 的普通会话可以通过 Android 原生执行层操作本机 App。MT 管理器、Reqable、浏览器等使用通用界面工具；Termux 另有官方命令接口；日志使用 Shizuku 的只读后端。日常使用无需电脑或 USB。

## 使用现有三种权限

手机工具直接读取聊天已有的权限选择器，不新增“批准任务”“开启连续控制”等开关。

| 现有模式 | 手机工具行为 |
| --- | --- |
| 仅可查看（read-only） | 读取当前 App 界面、截图、按 App 查看日志；不点击、输入、启动其他 App 或运行 Termux 脚本 |
| 工作区内修改（workspace-write） | 上述查看能力，加上现有受限文件工具对当前工作区的修改；通用 App 界面和 Termux 脚本无法保证只修改工作区，因此需要完全权限 |
| 完全权限（danger-full-access） | 直接打开和操作本机 App、截图、长按、输入、滑动，以及执行已授权的 Termux 命令；不用逐任务、逐 App 或逐动作批准 |

覆盖安装新版 APK后，在「服务 → 手机操作」完成 Android 必要的首次设置：无障碍、需要日志时的 Shizuku、需要命令时的 Termux。系统对侧载应用提示受限制的设置时，按系统提示处理。这些是 Android 后端权限，不是额外的 DSH 权限模式。

完成首次设置后，在聊天里选“完全权限”，直接说明任务，例如「用 MT 管理器查看下载里的测试文件」「打开 Reqable 检查我指定 App 的请求」「在 Termux 执行诊断并返回结果」。工具使用真实会话的权限，模型填写的 mode/owner 参数不能改变它。权限降级后，后续操作立即使用新模式。

屏幕上显示「停止操作」。停止会阻止当前指令继续调用，直到你发送新的指令或切换会话权限；已经发生的发送、删除或交给 Android/Termux 的操作不会自动撤销。密码字段、锁屏和必要的系统授权仍由本人处理。界面、截图、日志和命令输出进入所选模型会话。

QQ、子任务和外部手机工具箱不继承手机本机会话权限。外部工具箱仍使用其原有配对和原生授权流程。远程网页打开同一个手机 DSH 会话时共享其权限；本模块不按浏览器来源隔离同一会话。

## 按 App 读取运行日志

打开「服务 → 手机操作」中的 Shizuku，启动其服务，再点「授权日志读取」并允许授权。Android 11 以上可用无线调试在手机上启动 Shizuku；手机重启后通常需要重新启动。之后可直接说「查墨听D刚才运行的日志」等，DSH 使用实际 App 包名读取最近 Logcat。

`phone_app_logs` 只读取所选 App 的独立 UID，最多 1000 行和 128 KiB，不清空日志、不运行任意 shell，也不会在隔离失败时改为读取全机日志。共用 UID 的 App 会拒绝读取。App 未输出日志、缓冲区已覆盖或关闭了日志时可能为空；空日志不代表没有错误。崩溃或 ANR 的其他系统诊断记录、App 私有文件及已删除的历史日志不保证包含在内。常见令牌、密码、Cookie 会脱敏，无法保证识别每一种私密字段。

## Termux 命令

先安装官方 Termux 并打开一次完成初始化。手机操作页提供「Termux 首次接入设置」：复制设置命令到 Termux，由本人执行一次 `allow-external-apps=true` 设置，再返回授予「Termux 命令」权限。接入时可先让 DSH 执行 `printf dsh-termux-ok` 核对结果；权限已授予不等于 Termux 配置已生效。

`phone_termux_run` 使用官方 RUN_COMMAND 接口，在 Termux 自己的环境中运行脚本，立即返回任务标识；`phone_termux_result` 读取输出、错误和退出码。只在聊天现有的完全权限模式下可用。脚本最多 16000 字、运行时限 1–120 秒，需要已初始化环境中的 bash 和 coreutils/timeout。成功取回结果仍须检查退出码和实际效果。未知结果不能自动重发。输出有长度限制及常见凭据脱敏。

Termux 的文件访问、安装工具及网络能力依其实际配置和 Android 权限而定。停止操作或权限降级会取消结果回传和后续命令；已经提交的命令可能继续运行，需要时在 Termux 终止。脚本自身启动并脱离终端的后台服务也不能保证由时限或停止按钮终止。

## MT 与 Reqable

这两类 App 使用通用 `launch/read/screenshot/click/long_click/input/scroll/back/tap/long_press/swipe` 操作。截图需 Android 11 以上和支持图像的模型；文字模型可继续读取界面元素。界面未暴露完整元素时，可结合截图坐标操作。安全窗口、密码页面或系统拒绝截图时如实返回失败。

Reqable 的首次 VPN、证书及目标 App 对证书的信任需要本人配置。能启动抓包不等于能解密所有 HTTPS；证书固定或不信任用户证书的 App 可能只显示连接信息。DSH 应检查抓包的实际结果，并使用 App 的导出功能分析；本模块没有声称实现未经确认的 Reqable 私有 API。

## 开发与验证

私有 Unix socket 核验调用 UID，工具从真实 DSH 执行上下文绑定会话，原生层核对授权代次、目标 App、界面快照和操作标识。快照有效 30 秒，界面变化必须重新读取；坐标以原屏幕像素表示，截图返回缩放及裁切原点。外部任务最多 256 次调用，本机完全权限的一轮最多 4096 次；达到上限可再次同步现有会话权限，无需批准开关。超时和断线不重发变更操作。

已有插件和 shell 与 DSH 使用同一 UID/进程，本模块不能作为恶意插件沙箱。只安装可信插件。屏幕、日志和工具输出是外部数据，不是指令。

JSON CLI 保留原有开发及外部任务用的 `status/request/action/stop`。手机聊天使用绑定真实会话及现有权限的 DSH 工具；兼容的 request 工具无需原生确认。CLI 不提供修改聊天权限或自动授予系统权限的命令。离线 Android/Robolectric 与真实 DSH SDK 检查不能替代本人启用后的实机跨 App 验收，见 TEST.md。
