# DSH 知识库 0.2.0

入口：侧边栏“知识库”，或设置 → 知识库。两端共用响应式页面。

- 总览：真实笔记数量、分类、最近编辑、标签、近 12 个月新增趋势。
- 知识：Markdown/TXT 导入与去重、新建编辑、分类/标签/状态、搜索、关系图谱、版本历史及回收站。
- AI：选择 DSH 已有模型提问或整理草稿；资料不足时不调用模型。回答展示实际检索的原文与来源；引用编号会检查有效性，不等同于对回答事实自动背书。草稿需点击保存才写入笔记。
- 系统：问答模型、关键词或本机混合检索、索引更新、当前记忆范围、操作日志。授权复用 DSH 原有本机登录，不保存第二套 API 密钥。

导入目前支持 `.md` / `.markdown` / `.txt`，每个 2 MB，一次最多 20 个、共 12 MB。其他格式先转换为文本。最多 5000 篇笔记，每篇保存最近 30 个历史版本。删除进入回收站，可以恢复。

笔记主数据和历史保存在当前 `DSH_HOME/knowledge/workbench/state.json`；给既有本机 BGE 索引提供的 Markdown 副本在 `knowledge/notes/workbench/`。主数据原子保存；索引副本失败会明确报告，修复后更新索引可恢复。未完成向量索引时仍可使用关键词搜索。

显式选择“加上已允许的历史记忆”后，还需选择本机对话。检索遵守该对话已有的 off/project/related 模式及 Agent 来源；不会自动修改记忆范围。知识库索引开关不等于自动记忆召回开关。

图谱只展示真实的 `[[笔记标题]]` 链接或共同标签；不生成虚构关系。问答只在用户点击时将问题及最多 6 段相关资料发给所选模型，可以取消，最多等待 2 分钟；临时问答不落盘，点击“保存为笔记”后才成为持久资料。

电脑和手机各自保存在本设备；可导出 Markdown 后在另一端导入。现有“技能与经验传递”功能继续保留。此版本不承诺笔记自动同步。

验证：`node --test tests/knowledge.test.mjs`。用本机夹具检查保存冲突、导入失败、损坏文件保留、索引恢复、范围过滤、引用检查、取消及 SDK 契约。另需安装后实际打开页面、保存、搜索和重启验证。
